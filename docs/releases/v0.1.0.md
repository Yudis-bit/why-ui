Coding agents can read CSS. why-ui gives them runtime browser evidence.

This first release supports one explicitly armed Chrome tab, an authenticated local
bridge, and two MCP tools:

- `inspect_interaction`: actual browser target/blocker hits, sampled reachability,
  conservative stacking causality, and local source references where available.
- `verify_fix`: observe a source patch, reacquire the target after HMR/reload, rebuild
  the sampled surface, and independently return PASS, FAIL, or INCONCLUSIVE.

The release gates include real production-extension E2E on Linux/Windows, tarball
installation, and Vite/React 18 plus Next App Router/Turbopack/React 19 native-HMR checks.
No application activation events are used to establish clickability.

### Try it

1. Download and unzip `why-ui-extension-v0.1.0.zip` into a stable directory. In Chrome's
   `chrome://extensions`, enable Developer mode and load that directory unpacked.
2. Install the attached CLI tarball with `npm install -g ./why-ui-0.1.0.tgz` (Node 22.13+).
3. Run `why-ui doctor`, then `why-ui pair`. Enter its one-time token in extension Options.
4. Configure your agent to run `why-ui mcp --workspace /path/to/app`, arm your app tab,
   and move the pointer. See the [README](https://github.com/Yudis-bit/why-ui#readme).

Verify the downloaded archives against `SHA256SUMS.txt`. The release workflow builds
them from the tagged source only after validation passes. Distribution is GitHub-first;
no npm registry publication is claimed.

### Limits

Reachability and Safe Core are sampled estimates, not proofs of event-handler or
business-logic correctness. Closed shadow roots and iframe interiors remain opaque.
React internals and maps can be unavailable. Static source correlations are labeled
heuristic; uncertain mapping and target identity remain UNMAPPED/INCONCLUSIVE.
See [framework validation](https://github.com/Yudis-bit/why-ui/blob/main/docs/framework-validation.md)
and [security](https://github.com/Yudis-bit/why-ui/blob/main/docs/security.md).

Please share a small reproducible UI bug through the repository's Issues or Discussions.
Keep credentials and private application data out of reports.
